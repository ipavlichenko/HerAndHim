# AIGirla — locally verified catalogue candidate

User approved the brand **AIGirla**, preserving the simple wordmark and apricot
star already shown. The current bot is extended; no second bot is created.
No production deployment or public admission change was made in this task.

## Result

- 20 fictional adult heroines: 10 photographic and 10 explicitly 2D anime
  portraits, ages 21–54. All 10 existing story entries are retained.
- Name onboarding, adult confirmation, visual Telegram keyboard Mini App,
  character/episode resumption, and independent new episodes.
- User × character × episode paths isolate chat, memory, scene state and FTS.
  Explicit owner mapping keeps the previous Sarah episode in place.
- Per-user serialization includes generation, switching and initiative delivery.
  The original secured provider and shared budget remain in use.
- Separate static web surface; no owner data or privileged dashboard API.
- The landing reflects the supplied fantasy segment, with control over pace and
  boundaries, a large first-screen Telegram CTA, alternating styles under All,
  and an accurate privacy disclosure.
- AIGirla is the approved service name. `aigirla.com` had no .com registry record
  at 2026-10-25 16:37:12 UTC. No domain was bought, and checkout pricing was not
  verified. The full read-only naming research is retained in JSON files.

## Verification

Latest catalogue suite: **228 passed**. Combined with the isolated regression
processes in `regression-results.json`: **476 passed**, **1 known baseline
failure**. The photo error assertion expects `provider_request_failed` while
the baseline already returns `provider_unavailable; request_id=...`; the same
failure was observed on source baseline `3f4e9da`.

Ruff, JavaScript syntax, Git whitespace checks, and standalone Docker Compose
configuration validation passed. The application/container itself has not been
built or started on the server in this task. Browser checks covered 1280, 390
and 320 px, all 20 portrait assets, filters and profile display, exact style
alternation, first-screen CTA, and the expandable privacy notice. An 11 px
overflow at 320 px was corrected by stacking the filters.

No paid dialogue-provider calls and no Telegram messages were sent. The
200 character × story initialization cases are offline structural tests, not
proof of quality across 200 real model conversations. Real Telegram WebApp
handoff, provider replies, rollout and owner acceptance remain next.
